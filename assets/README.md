# Images

Every image on the site is here, cropped from the Behance boards, the three StoryMaps and the Tulsa final presentation. Behance recompresses, so if you ever have a higher-quality export, save it under the same file name and the page picks it up.

portrait.jpg is a two-tone print (aubergine ink on paper) of a café photo, 900 by 1125. To replace it, save a new photo under the same name at the same size; the two-tone treatment lives in the session scratchpad script portrait/duotone.js (CoreImage via osascript).

Rules if you add images: PNG for interface screens, JPEG for photographs and renders, 1600 pixels wide, under 500 KB each where possible.

## Portrait
`portrait.jpg` is a 1 by 1 placeholder. Replace it with a photo of Lochan (a 4:5 portrait, about 900 by 1125 pixels, works best) and the About section shows it automatically. Nothing else to change.
